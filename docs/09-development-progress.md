# 09 开发进度

状态 **设计基线 v0.2** · 2026-11-25

## 项目分析

项目从空目录起步。业务主线是「固定数据与规则版本 → 批量执行候选模型或 Agent → 稳定交付可追溯评分 → 依据人工复核和回归报告作发布判断」。

| 风险 | 当前设计措施 | 首次验证 |
| --- | --- | --- |
| 消息丢失、重复、执行中断导致数据不一致 | PostgreSQL 事务发件箱、执行租约、恢复扫描、终态唯一约束 | M2 故障注入 |
| 低覆盖率或裁判偏差误导发布 | 质量/运行失败分开统计，人工金标与独立验收集，覆盖不足出证据不足 | M3 校准，M6 报告 |
| Agent 调用产生不可控副作用或轨迹缺失 | 注册式只读夹具，记录期望路径与执行迹证，独立业务判定 | M4 夹具回归 |

M0 已形成需求、选型、架构、数据库、API、测试、评测和运维文档。应用代码、测试执行、模型评测和部署实测按里程碑开展。

已确定 FastAPI API、M2 Celery 样本级进程并行及 M5 Vue 3 管理台。只有压测确认 Worker 主要等待模型 I/O 且供应商额度有余量，才进入 `asyncio` 单进程并发试验。 [技术决策与开源参考](02-tech-stack.md)
