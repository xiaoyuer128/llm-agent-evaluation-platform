# 01 项目需求文档

状态 **设计基线 v0.1** · 2026-11-25

## 背景与目标

模型升级和 Agent 工具改动需要重复跑同一批业务场景。人工抽查难以复现，候选回答、队列失败、裁判失效和工具轨迹常分散在不同日志中。平台把样本、执行和评分绑定到可查询的版本，支持 QA 和研发共同审查发布回归。

## 用户和权限

| 角色 | 工作 | 权限 |
| --- | --- | --- |
| 读者 viewer | 查看历史运行及评测摘要 | 读取数据集元数据、模型元数据与运行摘要 |
| 执行者 operator | 维护样本、发起测试、分析失败 | 继承 viewer，管理数据集版本、发起和取消运行、读样本结果与工具轨迹 |
| 管理员 admin | 管理受控模型、授权与排查 | 继承 operator，拥有模型配置及运行额度的运维权限 |

生产身份由组织的身份源约束。接入方式和数据外发审批人见 [决策清单](09-development-progress.md#待确认决策)。

## 使用流程

1. 执行者创建数据集并导入经脱敏的 JSONL。预览校验通过后发布版本。
2. 选择数据集版本、一个或多个受控候选配置、评测配置和可选的重复次数。提交立即获得运行 ID。
3. 平台按样本并行执行，同步展示各候选的进度和故障分类。运行可以请求取消。
4. 查看每个候选的有效样本数、质量、延迟和 Token。对失败样本查候选回答、评分证据和受控 Agent 工具轨迹。
5. 对同配置的基线和候选进行配对比较。发布负责人依据回归结果和人工复核作出发布决定。

## 功能和验收

| ID | 优先级 | 要求 | 验收 |
| --- | --- | --- | --- |
| FR-01 | P0 | 统一模型和 Agent 配置 | 同一数据集可选多个配置，接口使用统一 ID；返回兼容的回答、用量与错误结构。密钥由服务端解析 |
| FR-02 | P0 | 数据集导入、发布、历史留存 | 导入错误返回行号；同批数据全成或全败；发布后样本及评分期望不可修改，修订通过新版本 |
| FR-03 | P0 | 批量任务、状态、取消与异常重试 | 提交异步返回；重复请求和队列重投只有一条逻辑结果；展示终态与进度；已完成结果在取消后可查 |
| FR-04 | P0 | 规则评分、延迟和 Token | 用带预期答案的夹具独立重算分数；缺失用量显示空值及覆盖率；可区分失败和零分 |
| FR-05 | P0 | LLM-as-a-Judge | 结构化评分与裁判配置可追溯；保存评分理由和证据；裁判异常显式可见；通过人工金标校准 |
| FR-06 | P0 | LangGraph Agent 评测 | 有确定性隔离工具；可追踪调用顺序、耗时、参数摘要；完成率和工具调用准确率可用夹具验算 |
| FR-07 | P0 | 可视化操作、结果查询与可比性 | 可在管理台导入和发布数据集、提交运行并查看进度。运行、候选、样本三级查询显示分母、覆盖率和失败计数，标识跨版本差异 |
| FR-08 | P0 | 部署与可运维 | pytest 可在 CI 运行；Compose 提供开发部署；提供故障排查、备份恢复和上线验收 |
| FR-09 | P1 | 自动生成发布回归报告 | 以版本化阈值给出通过、未通过或证据不足；回链关键失败样本 |

首期面向单个内部工作空间。Vue 3 管理台覆盖数据集、评测提交、运行状态、候选结果对比和样本详情。Swagger 用于接口调试。多租户、在线流量评估和生产工具写操作留待后续立项。

## 非功能目标

下列数值用于首轮测试，生产规模与正式 SLO 待确认。

| 维度 | 首轮验收目标 |
| --- | --- |
| 容量 | 单次导入最多 1,000 行和 5 MiB；一次运行最多 1,000 个执行项，执行项数为样本 × 候选 × 重复次数 |
| API | 测试环境 20 个并发读请求持续 10 分钟，摘要和结果列表 P95 ≤ 500 ms，意外 5xx 比例 < 1% |
| 可靠性 | 通过数据库提交后、消息发布后、Worker 写回前三个故障窗口，逻辑结果无丢失、无重复写入 |
| 可追溯 | 从结果定位数据集版本、候选配置、评分配置以及各次尝试；版本或字段缺失可观察 |
| 数据保护 | 业务数据脱敏后入库；权限越界访问被拒绝；日志与安全检索不返回密钥或完整敏感请求 |
| 可恢复 | 在预发记录备份恢复与积压恢复实测时间；建议 RPO ≤ 24 小时、RTO ≤ 4 小时 |

性能和评测口径分别见 [测试计划](06-test-plan.md) 和 [AI 评测方案](07-evaluation-design.md)。
